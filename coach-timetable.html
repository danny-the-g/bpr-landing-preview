BPR Coach Timetable

Click and drag to block the times the selected coach wants to host exercise calls. Switch the timezone to see every block converted live.

Coaches

Each cell is a 30-minute slot. Blocks are stored once and converted for whichever timezone you pick, so a coach sets availability in their own timezone and everyone else sees it in theirs. Conversions use the current week, so around daylight-saving changes double-check the hour. Everything saves in this browser. Use Export to share the file or move it to another device.
